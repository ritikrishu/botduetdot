Security policy

Pair only with servers you trust. Treat pairing links and access tokens as credentials; do not post them publicly. Prefer HTTPS or Tailscale for remote access. Plain LAN HTTP does not itself encrypt traffic. Keep your app, server and coding agents updated, review permissions and maintain backups.

For a suspected vulnerability, open a minimal report in repository Issues asking how to share details. Do not post exploits against live systems, tokens, private logs or sensitive data. A private reporting channel and response-time guarantee are not currently promised.
