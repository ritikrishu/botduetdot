Privacy policy

Updated 20 November 2026. This policy covers BotDuetDot, published by RemoteX Services LLP, and this website.

Your devices and server

Projects, conversation history, settings and attachments are stored on your devices and the server you pair with. BotDuetDot has no account system or developer-operated content storage. Android sends prompts, selected files/photos/videos and device connection metadata (including device identifiers, label/model, OS and app version) to that server. If you choose server transcription, recorded audio is uploaded there; local Android transcription is also available.

What leaves your devices

Your chosen coding agents and AI providers receive content needed to perform your requests under their own policies. GitHub receives requests and repository data when you use GitHub source-control features; release/update checks and downloads also contact GitHub. The desktop server also reads AI-tool vendors' public release channels (for example Anthropic for Claude Code and Meta for Muse Code) to offer command-line tool updates; these requests carry no conversation content. Pairing and remote control use your configured LAN or Tailscale connection. Tailscale use is subject to its policies. Plain LAN HTTP is supported and is not encrypted by BotDuetDot; use HTTPS or a trusted encrypted network for remote access.

BotDuetDot does not provide T3 Connect, push notifications, advertising or default remote crash reporting. Product analytics is off by default with no configured analytics recipient. A server operator can explicitly enable analytics by supplying a telemetry setting, endpoint and key. That endpoint can then receive event timestamps, usage/provider/model statistics, token counts, duration/status, app/OS information, installation identifiers and hashed provider-account/device identifiers. These identifiers are pseudonymous, not guaranteed anonymous. Connected phones can contribute metadata; this is a server setting, not a per-phone consent switch. Operators can separately configure exports of logs, traces and metrics to their own collectors.

Retention and deletion

You and your server operator control local history, files and backups. Uninstalling the phone app does not remove server history. Contact the operator of a paired server to remove its stored data, and your chosen providers or analytics recipient about their retention and deletion. Turning analytics off stops future delivery, not deletion of previously received events. No BotDuetDot account exists to delete.

Website and contact

This static site has no tracking code or external scripts. GitHub Pages hosts it and may process request information such as IP addresses under GitHub's privacy policy. Reports you submit through GitHub Issues are handled by GitHub and may be public. Contact RemoteX Services LLP at hi@remotestate.com for privacy requests, or through repository Issues. Do not include credentials, private code or personal records.
